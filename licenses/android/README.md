# Android dependency acknowledgments

`supplements.json` records exact coordinates, compiled-artifact SHA-256 digests, original text digests and upstream provenance. It supplements the notices already present in Maven AAR/JAR artifacts. Normal packaging is offline: `scripts/native-android-notices.py` verifies all text digests and refuses a reviewed coordinate whose artifact bytes changed. An unreviewed version stays unresolved. These files retain their upstream licenses; Weekaboo's MIT license does not replace them.

The runtime dependency graph is pinned in `android/app/gradle.lockfile`. Review a dependency update together with its license/NOTICE changes. To deliberately regenerate the lock, run Gradle `:app:dependencies --write-locks` with the supported JDK, inspect the diff, collect new notices from the exact published POM/source archive or release tag, and update the digest-bound supplement. Ordinary builds must not use `--write-locks`.

AndroidX Apache-2.0 declarations come from the exact published POMs. Full Apache text is included, with original copyright headers and standalone notices from the matching Google Maven sources archives where published. The two ConstraintLayout 1.1.3 artifacts have Apache-2.0 POM declarations but no published source archives at those coordinates; their full license is supplied without inventing copyright notices. Original compiled-artifact notices remain preserved.

Microsoft, Square, Kotlin, Yubico, OpenTelemetry, Cordova and other supplements retain exact-tag/source provenance. Kotlin's runtime-specific BSD, Boost, GWT and Guava notices and Cordova's NOTICE are included. Google client SDKs remain governed by vendor terms; original embedded third-party texts are retained. The [SDK terms](https://developer.android.com/studio/terms), [client-library overview](https://developers.google.com/android/guides/overview) and [notice guidance](https://developers.google.com/android/guides/opensource) were reviewed on 11 September 2026 for standard Android application use. No SDK/toolchain or Google Play services system application is redistributed by this source tree.

The transitive `com.microsoft.device.display:display-mask:0.3.0` dependency is excluded from MSAL. Its one class is a compile stub whose methods throw; MSAL 8.4.2/common 24.6.0 guards the optional OS hinge query and catches missing-class failures. The release instrumentation test exercises that actual fallback on Android. Weekaboo does not claim Surface Duo hinge support. The exclusion also removes the need for the separate Microsoft Duo Maven feed.

Completeness means the resolved acknowledgment inventory is covered. Store acceptance, provider policies, final artifact tests and project/media rights remain separate release checks. Do not use a successful collector result as a production-readiness declaration.
