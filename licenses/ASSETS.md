# Asset provenance and redistribution

The root MIT license covers Weekaboo's original code. It does not replace upstream dependency, font, SDK or trademark terms. This inventory distinguishes the media included in the source from private design experiments.

| Asset | Source / scope | Status |
| --- | --- | --- |
| `public/brand/weekaboo-mark.svg`, `weekaboo-peek.svg` and derived application icons | Original vector implementation based on the user-selected AI-assisted calendar character; real Nunito wordmark | Generated-concept provenance retained privately; no real person's likeness or third-party character requested |
| `public/brand/audio/*.mp3` | Thirteen approved ElevenLabs `eleven_v3` stock-voice greetings, generated 9 September 2026; short pitch/tempo/level postprocessing | Paid-generation status still needs confirmation before public media redistribution. Do not describe these clips as MIT-licensed sound samples |
| `public/fonts/Nunito-Variable.ttf` | Nunito | SIL OFL text retained in `Nunito-OFL.txt` |
| `website/assets/android.svg` | Official Android robot compatibility illustration | CC BY 3.0 attribution in website credits |
| `website/assets/google-calendar.webp` | Official Google Calendar compatibility artwork | Google brand terms; identifies the integration, not an endorsement |
| Device/UI icons | Lucide | ISC notice retained/bundled; not Apple or Microsoft logos |

Unapproved audio and unused raster concepts/motion-study pages are preserved in ignored local design archives, outside the distributed runtime and proposed source tree. User tokens, voice-service keys and generation-account details are not part of the project.

ElevenLabs generation records establish the model, stock voices, scripts, transformations and approval hashes; they do not establish the subscription tier on the generation date. Publication is held until that fact is resolved. Official references checked 11 September 2026: [publishing generated content](https://help.elevenlabs.io/hc/en-us/articles/13313564601361-Can-I-publish-the-content-I-generate-on-the-platform) and [terms](https://elevenlabs.io/terms-of-use). These are TTS outputs, not Sound Effects outputs; do not apply the latter's separate sample-library rules by assumption.

See [third-party attribution](../docs/attribution.md) for adapted code, fonts, timezone data and SDK notice obligations. This inventory is not a claim that all assets or external SDK binaries share one license.
