## Mantel

Source: https://github.com/heyitsmiike101/mantel at commit `83537f72b80c0bd7d23222724b5996974ab6d3fa` (audited local base). Copyright © 2026 Mantel contributors. Full MIT notice: [Mantel-MIT.txt](../licenses/Mantel-MIT.txt).

Selected `backend/app/services` Google API/OAuth, CalDAV/iCloud, recurrence, sync engine, push/pull signal and provider modules were adapted into `backend/weekaboo/integrations`. The event API and small schemas/errors/time helpers were adapted into Weekaboo's equivalents. Relevant provider, recurrence and event regression cases were adapted into `backend/tests`.

Changes include Weekaboo-owned account/calendar/event models, neutral remote-ID fields, removal of household/local-calendar dependencies, our configuration and encrypted storage, serialized writes, and in-place full-resync reconciliation preserving pending changes and event IDs. The original Mantel frontend and non-calendar subsystems were not copied into the runtime.

Local desktop packaging inventories bundled SDK dependencies and preserves available upstream LICENSE/NOTICE files under `licenses/desktop` inside the app archive, plus Electron's LICENSE and Chromium notices. `scripts/desktop-notices.mjs` uses the shared module collector and fails packaging if a bundled dependency has no notice text. Renderer builds independently inventory their bundled packages through `scripts/shared-notices.mjs`, preserving upstream license texts under `licenses/shared` in browser, Android, iOS and desktop renderer assets. `scripts/verify-bundled-notices.mjs` checks the source texts byte-for-byte and verifies their presence in the actual APK, AAB, archive, IPA and Mac app. Complete native-mobile SDK notices, Weekaboo's final project license/owner and generated mascot/audio redistribution rights remain public-release gates. No commercial-license purchase or public release is implicit.
